# Mieletünk 💕

Egy kis 2D szimuláció két cuki figurával (Pufi 🐰 és Mogyi 🐻), akik a réten éldegélnek.

**Mit lehet csinálni?**
- 🍓 **Etetés** – gombbal, vagy koppints bárhova a fűre és lehull egy finomság
- 🤗 **Ölelés** – odatotyognak egymáshoz és megölelik egymást
- 🌳 **Séta** – kézen fogva elmennek sétálni (🏠 *Haza* gombbal hazahívhatod őket)
- 💃 **Tánc** – kis bulit csapnak zenével
- 😴 **Alvás** – leszáll az éj, összebújva alszanak, közben töltődik az energiájuk
- Koppints rájuk, és kuncognak / ugranak egyet
- A nevükre koppintva átnevezheted őket ✏️
- Jóllakottság / boldogság / energia mérők; az állapot a böngészőben elmentődik

Telefonra optimalizált, a böngésző „Hozzáadás a kezdőképernyőhöz” menüjével appként is elmenthető.
Egyetlen `index.html`, nincs szükség telepítésre vagy buildre.
